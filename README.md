# 宅建 出る順

類題を含めた出題頻度の「出る順」で学ぶ宅建学習アプリ（Web版）。iPhoneのSafariで開き、共有ボタン →「ホーム画面に追加」でアプリのように使えます。

- `index.html` / `style.css` / `app.js`：Web版（GitHub Pagesで公開）
- `data/topics.json`：55論点（ひとことで・用語・解説・具体例・ひっかけ注意・覚え方・要点まとめ）
- `data/questions.json`：247問（一問一答・四肢択一）
- 画面：ホーム／学ぶ（出る順・科目別・未読から）／解く（出る順・科目別・苦手順・未回答で並べ替え）／記録
- `ios/`：元のSwiftUI版（Xcodeプロジェクト。v1のまま）

学習記録はブラウザ内（localStorage）に保存されます。
